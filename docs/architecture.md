# SentinelHub Architecture

## Overview

SentinelHub is a security monitoring project designed to demonstrate how synthetic security events can be collected, processed, and displayed through a simple dashboard.

## Project Structure

- `backend/` — Flask backend API
- `frontend/` — Security monitoring dashboard
- `data/` — Synthetic security event data
- `tests/` — Automated tests
- `docs/` — Project documentation

## Data

The project uses synthetic security events only. No real customer information is used.

## Components

The backend provides API endpoints for the dashboard.

The frontend displays system status and security-event information.

The data directory stores synthetic event records.
